# Klassenbuch Schlagzeug

Web-App (installierbar auf iPad, iPhone und Mac) für den Perkussionsunterricht: SuS, wöchentliche Lektionsnotizen, Präsenz, Lehrplan AP, Jahreskalender und Noten-Bibliothek.

- Öffnen: https://klassenbuch.adrianpopp.ch – in Safari «Teilen → Zum Home-Bildschirm».
- Daten liegen auf dem Gerät; optionaler Sync ist Ende-zu-Ende-verschlüsselt.
- Dieses Repository enthält nur den App-Code und den Lehrplan, keine persönlichen Daten.
